## Project Overview

This project was created as an experiment to explore and practice implementing Clean Architecture using NestJS.

The main purpose of this project is to simulate a simple process of defining business requirements and developing a project structure based on those requirements. It serves as a learning exercise to better understand how to organize code, separate concerns, and apply architectural principles in a real-world-like scenario.

This repository is primarily intended for learning, experimentation, and improving personal development skills in backend architecture and project design.
